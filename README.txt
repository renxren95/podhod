ПОДХОД — самостоятельная версия
================================

Что внутри: index.html (само приложение), manifest.webmanifest и sw.js (установка на главный экран и работа без интернета), иконки.

Как выложить бесплатно (около 2 минут, без кода)
1. Распакуй архив, получится папка «podhod».
2. На компьютере открой https://app.netlify.com/drop и войди (можно через Google или GitHub, бесплатно).
3. Перетащи папку «podhod» целиком на страницу. Через несколько секунд появится ссылка вида https://что-то.netlify.app
4. В настройках сайта (Site configuration → Change site name) можно задать понятное имя, например podhod-liza.netlify.app.

Как поставить на телефон
• iPhone: открой ссылку в Safari → «Поделиться» → «На экран „Домой“».
• Android: открой ссылку в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
После первого открытия приложение работает и без интернета.

Перенос тренировок из версии в Claude
1. В Claude откройте «Подход» → Настройки → «Скопировать данные».
2. В новом приложении: Настройки → «Вставить данные» → вставь → «Восстановить».
Удобнее делать это на одном телефоне: скопировал в одном, вставил в другом.

Важно
• Данные хранятся только на этом телефоне, в памяти браузера. Время от времени нажимай «Скачать файл» в настройках, чтобы была резервная копия.
• Если обновишь приложение (перетащишь новую версию папки в Netlify в раздел Deploys), данные на телефоне сохранятся.
